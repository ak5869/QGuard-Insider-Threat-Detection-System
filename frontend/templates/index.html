How Quantum ML Works
A) Variational Quantum Classifier
1. PCA reduces 27 features → 8 dimensions
2. Features encoded as RY rotation angles on 8 qubits
3. 3 variational layers: RY + RZ rotations (trainable)
4. CNOT entanglement links adjacent qubits
5. Measure ⟨Z⟩ expectation value → threat probability
6. Adam optimizer trains rotation parameters
B) Quantum Kernel SVM
1. Same angle encoding as VQC
2. Kernel K(x₁,x₂) = |⟨φ(x₁)|φ(x₂)⟩|²
3. Measures similarity in quantum Hilbert space
4. Classical SVM trained on quantum kernel matrix
5. Captures non-linear patterns classical SVM misses
